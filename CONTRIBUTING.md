# Contributing to vllm-mlx

Thanks for helping improve vllm-mlx. Bug fixes, performance improvements,
documentation, benchmarks, and support for additional Apple Silicon hardware or
models are all welcome.

Read the [contribution guide](docs/development/contributing.md) for setup,
testing, code style, and pull request instructions.

Before opening a pull request:

1. Keep the change focused and include regression coverage when practical.
2. Run the relevant tests and code-quality checks.
3. Explain the user-visible impact and any Apple Silicon hardware used for testing.

For questions or proposed features, start with a
[GitHub issue](https://github.com/waybarrios/vllm-mlx/issues).
